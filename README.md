# RISC-V 32-bit Processor

## Overview
This project aims to design and implement a 32-bit RISC-V processor using SystemVerilog.

The project follows a structured hardware development workflow, including RTL design, simulation, verification, and eventually FPGA implementation and physical design.

## Architecture
- ISA: RISC-V
- Architecture: RV32I
- HDL: SystemVerilog

## Project Structure
- rtl/ : RTL design files
- tb/ : Testbench files
- verification/ : Verification environment
- docs/ : Project documentation
- scripts/ : Automation scripts
